Overview

VPA Internal Transfer - Receipt Control is an add-on module for VPA Accounting Internal Transfer that adds receiver-focused cash control with custodian confirmation workflow. Nobody can deposit funds into a cash/bank account without the custodian's authorization - providing an additional layer of financial control.

Key Control Principle
After approval, journal entries are only created after the destination custodian confirms receipt. This ensures the person responsible for the receiving account verifies the funds before posting.

Dispute Path
If the receiver identifies an issue (wrong amount, not received, etc.), they can raise a Dispute which must be resolved before the transfer can proceed.

Key Features

Receipt Confirmation
Custodians must confirm they received the funds before journal entries are created. Complete control over incoming deposits. 		Journal Custodians
Assign primary and backup custodians to each bank/cash journal. Clear responsibility and backup coverage.
Dispute Handling
Receivers can raise disputes with reasons (amount mismatch, not received, partial receipt). Full resolution workflow. 		Reassignment
Transfer Managers can reassign pending transfers to different custodians when the original is unavailable.
Permission Hierarchy
Three-tier fallback: Primary Custodian, Backup Manager, Transfer Manager (emergency). Always someone can act. 		Feature Toggle
Enable/disable receipt confirmation in settings. Opt-in when ready, gradual rollout by journal.
Enhanced Reports
PDF voucher extended with Receipt Confirmation section, Dispute Details, and Received column in Approval Trail. 		Activity Notifications
Automatic activity creation for custodians when transfers need their confirmation.
