Overview

VPA Document Layout is a comprehensive document design solution that gives you complete control over your Odoo reports. Create professional, branded documents for sales orders, invoices, purchase orders, and manufacturing orders with an intuitive visual configuration system and live preview.

Key Features

Multiple Templates
Support for various report templates including Standard, Modern, and Quotation Pictures with product images! 		Live Preview
See your changes in real-time as you configure. No more guesswork - instant visual feedback for every adjustment!
Custom Header/Footer
Fully customizable header and footer design with logo positioning, company details, and custom HTML sections! 		Table Styling
Professional table styling with gradient backgrounds, accent borders, and multiple style options (Bubble, Striped, Bordered)!
WeasyPrint Support
Superior CSS rendering with WeasyPrint PDF engine. Automatic fallback to wkhtmltopdf if not available! 		Multi-Company
Full multi-company support with separate configurations per company. Perfect for holding companies!
Backup/Restore System
Complete data protection with automatic backups before uninstall. Easily restore templates after reinstallation. 		Color Customization
Full control over primary/secondary accent colors, header text, body text, footer text, and backgrounds!
