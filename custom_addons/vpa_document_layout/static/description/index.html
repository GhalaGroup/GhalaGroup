⚙️ How It Works

Get started in 3 simple steps

1

🎨 Configure Layout

Open App: Launch "VPA Layout" from the app drawer

Customize: Configure header, footer, colors, and table styles

Preview: See live preview as you make changes

2

✅ Enable VPA Layout

Settings: Go to Settings → Companies → Your Company

Configure: Click "Configure Document Layout" button

Select: Choose "VPA Document Layout" and save

3

🚀 Generate Reports

Sales: Print quotations and orders with your layout

Invoices: Professional branded invoices automatically

All Reports: Every document uses your VPA layout!
