Overview

By default, Odoo lets on-hand stock fall below zero - deliveries, transfers, manufacturing consumption, scrap, inventory adjustments and Point of Sale all proceed even when there is no stock to take. This quietly corrupts inventory accuracy and product costing. VPA Stock Sentinel enforces non-negative inventory at the single point every stock decrement passes through, so no operation slips past it. Choose a strict Hard Block or a manager-gated Soft Warn per company, set exceptions where you genuinely need them, and keep a complete audit trail of every event.

Key Features

Total Coverage
One enforcement point catches deliveries, internal transfers, manufacturing consumption, scrap, inventory adjustments and POS pickings. No pathway is missed. 		Per-Company Control
Enable enforcement and pick the mode for each company from Inventory Settings. Off by default - nothing changes until you switch it on.
Hard Block or Soft Warn
Hard Block stops the operation outright. Soft Warn lets an Inventory Manager push it through - but only after entering a mandatory reason that is logged. 		Manager Override with Reason
The override is gated to a dedicated security group and requires a typed reason, recorded against the document for full accountability.
3-Tier Exceptions
Allow negatives for a specific product, a product category (inherited by child categories) or a stock location - precisely where your business needs them. 		Block Log & Audit Trail
Every block, warning and override is recorded with product, location, warehouse, on-hand, requested quantity, shortfall, user, document and reason - with chatter.
Manager Alerts
Notify chosen users with a to-do activity the moment a block or override occurs, so they can restock or investigate immediately. 		Clear, Detailed Messages
Block messages spell out the product, location, on-hand, requested quantity, resulting quantity and the exact shortfall - never a cryptic error.
Cleanup Report
A "Currently Negative Stock" report lists products already below zero, so you can fix existing data before turning enforcement on. 		Multi-Company & UoM-Safe
Full multi-company support, with quantities correctly handled across unit-of-measure conversions.
Inventory Adjustment Approval (optional)
Require manager approval for manual inventory adjustments (the Update Quantity / On-Hand screen), increase or decrease. The change is held as a request and stock does not move until an approver approves it. Per-company toggle; approvers can approve their own requests; rejections leave stock untouched; every request is tracked with full chatter under Inventory → Operations → Adjustment Approvals.

Security & Access Control

Builds on standard Odoo Inventory security groups:

Access Control
  • Inventory User: Subject to enforcement; can read the block log
  • Override Manager: Can force a negative operation with a mandatory reason
  • Settings: Configured by the System Administrator per company
  • Company Rules: The block log is scoped to each company
 Audit Features
  • Block Log: Every block, warning and override recorded
  • Chatter: Each log entry carries full message history
  • Override Reason: Required and stored for accountability
  • Manager Alerts: To-do activities on every event
