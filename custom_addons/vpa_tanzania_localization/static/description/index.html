Overview

VPA Tanzania Localization is a comprehensive localization module for Tanzanian businesses with TRA (Tanzania Revenue Authority) compliance. Provides proper handling of TIN and VRN tax identification numbers, complete ward database with all 31 regions, format validation, and unique constraints. Perfect for businesses requiring TRA-compliant invoicing.

Key Features

TIN & VRN Management
Separate fields for Tax Identification Number (TIN) and VAT Registration Number (VRN) with automatic format validation following TRA guidelines. 		Smart Address Auto-Fill
Select a ward and watch as the system automatically fills region, city, and country. Intelligent cascading saves time and ensures accuracy!
Complete Ward Database
Pre-loaded with all 31 Tanzania regions and 40+ major wards including detailed Dar es Salaam districts (Kinondoni, Ilala, Temeke, Ubungo, Kigamboni). 		TRA Format Validation
Automatic validation ensures TIN follows 9-digit format (123-456-789) and VRN follows 40-XXXXXXX-X format as required by Tanzania Revenue Authority.
P.O. Box Support
Replace generic "Zip" field with Tanzania-specific "P.O. Box" - matching how addresses actually work in Tanzania. 		Data Migration Safe
Seamlessly replaces old partner_vat_number module while preserving all existing VRN data - zero data loss guaranteed.
Unique Constraints
SQL-level unique constraints prevent duplicate TIN and VRN numbers across all partners in your database. 		Audit Trail
Complete tracking of changes to tax identification numbers. Know who changed what and when.
