⚙️ How It Works

Get started in 3 simple steps

1

📥 Install

Search: Find "VPA Login Theme" in Apps menu

Click Install: Module installs in seconds

Ready: Navigate to Settings → VPA Application → Login Theme

2

🎨 Configure

Choose Preset: Select from 6 pre-built themes

Or Customize: Use color pickers to create your own

Adjust Logo: Set perfect logo size and position

3

✅ Enjoy!

Save Changes: Click Save button

Instant Apply: No server restart needed

View Result: Refresh login page to see your branded login!
