VPA Production Studio - Manufacturing

Manufacturing Orders with Template BOM Support & Variance Tracking

Track Material Variance in Manufacturing

Create Manufacturing Orders from Master BOMs with template lines. Workers select actual products from category-filtered dropdowns. Track planned vs actual quantities with automatic variance calculation.

Key Features

Template Line Support

Create MOs from Master BOMs with category-based template lines. Placeholder products are automatically used until worker selects actual materials.

Variance Tracking

Track Master BOM Qty vs Physical Qty Used with auto-calculated variance. See variance as quantity and percentage for each component.

Category-Filtered Selection

Workers select actual products from dropdown filtered by BOM category. Only products in the matching category are shown.

Validation & Warnings

MO cannot be completed until all template lines have actual products. Warning banner shows when product selection is required.

Variance Tracking Columns

Column Description
Master BOM Qty Original quantity from Master BOM template line
Physical Qty Used Actual quantity physically consumed (entered by worker)
Variance Difference: Physical - Master (positive = over-consumed)
Variance % Variance as percentage of Master BOM Qty

How It Works

  1. Create MO from Master BOM: Select a Master BOM with template lines
  2. Template Lines Appear: Components show placeholder products with category info
  3. Select Actual Products: Workers click product dropdown filtered by category
  4. Enter Physical Quantities: Workers enter actual quantities used
  5. Track Variance: System auto-calculates variance (Physical - Master)
  6. Complete MO: Validation ensures all products are selected before completion
