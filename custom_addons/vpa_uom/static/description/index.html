📋 Overview

VPA Unit of Measure provides product-specific alternative units of measure with custom conversion factors. Similar to SAP's Alternative Unit of Measure (AUoM) functionality, this module allows you to define different conversion factors for the same UoM across different products — something standard Odoo cannot do.

For example: 1 Board = 2.9768 m² for MDF 18mm, but 1 Board = 2.88 m² for OSB. Store your stock in the base unit, then sell, buy, transfer, and manufacture in the units your customers and suppliers actually use — with automatic conversion everywhere.

VPA Unit of Measure is also the foundation module of the VPA suite, used by VPA SKU Generator and other VPA apps.

✨ Key Features

📐

Product-Specific Conversions

Define unique conversion factors per product, like SAP AUoM. 1 Board = 2.9768 m² for MDF, but 2.88 m² for OSB — each product keeps its own factor.

🛒

Sales Integration

Sell in alternative UoM with automatic conversion to the base UoM. The customer sees Boards, your stock stays in m².

📦

Purchase Integration

Buy in alternative UoM (pallets, boxes, packs). Order and invoice in the supplier's unit while stock is kept in yours.

🏭

Stock & Manufacturing

Transfer inventory using any configured UoM and use alternative UoM in BOMs and production orders for flexible unit handling.

📊

Enhanced Stock Views

See stock on hand in both base and alternative UoM across list, kanban, and stock reports — all alternative UoMs displayed.

🔖

Barcode Support

Assign unique barcodes to each alternative UoM. Scan in stock operations and auto-fill with the correct conversion.

📦

Packaging Fields

Qty per package and packaging name fields on each conversion, with barcode uniqueness validation across products and packagings.

⚙️

Configurable Rounding

Set decimal precision per conversion with 4-decimal accuracy (16, 4) for exact factors like 2.9768.

💾

Backup & Restore

Export and import conversions at any time, with automatic backup before uninstall. Multi-company support with separate factors per company.

🔄 How It Works

Get Started in 3 Simple Steps

Step 1 Install & Configure
Install "VPA Unit of Measure" and configure via Inventory → Configuration
Step 2 Define Conversions
Open the product form → Alternative UoM tab and add e.g. 1 Board = 2.9768 m²
Step 3 Use Everywhere
Sell in Boards, stock adjusts in m² — view stock in both UoMs in reports

💡 Typical Use Cases

  • 🪵 Sheet Materials: Plywood, MDF — store in m², sell in Boards
  • 🧪 Liquids: Store in liters, sell in bottles/containers
  • 🧵 Textiles: Store in meters, sell in rolls
  • 🔩 Hardware: Store in units, sell in boxes/packs
