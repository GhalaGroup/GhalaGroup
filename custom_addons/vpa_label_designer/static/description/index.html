Design & Print ZPL Labels to Zebra Printers from Odoo 19

📋 Overview

VPA Label Designer brings professional thermal label design and printing to Odoo 19 Enterprise. Design labels on a visual canvas with text, barcodes, QR codes, dynamic variables, lines, boxes, and images — then print directly to Zebra printers over the network or through the Zebra Browser Print SDK. The module generates native ZPL II code for every element, so labels print pixel-perfect at true printer resolution.

Print product labels from Products, Purchase Orders, Manufacturing Orders, Stock Pickings, and Lots, with quantities pre-filled from document lines and fully editable before printing. Dynamic variables resolve real record data — including product variants, packaging, prices with automatic VAT notes, and alternative Units of Measure — at print time.

✨ Key Features

🎨

Visual Template Designer

Design labels on an interactive drag-and-drop canvas with a grid overlay. Position text, barcodes, QR codes, variables, lines, boxes, and images exactly where you want them.

📐

Label Size Management

Create custom label sizes with automatic millimeter-to-dots conversion for your printer's resolution, including RFID-capable label formats.

⚡

Native ZPL II Engine

Every element is compiled to Zebra Programming Language (ZPL II) — the printer's native language — for crisp, fast, reliable output on any Zebra thermal printer.

🔤

Dynamic Variables

Resolve any field with dot-notation paths (e.g. product_id.categ_id.name). Built-in variables cover product data, variants, packaging, prices with automatic Incl./Excl. VAT notes, and more.

👁️

Live Label Preview

See a rendered preview of your label — including barcodes — while designing, so what you approve on screen is exactly what prints on the roll.

🖨️

Direct Network Printing

Send ZPL straight to Zebra printers over TCP (port 9100), or print client-side via the Zebra Browser Print SDK. Per-printer X/Y offsets fine-tune physical alignment.

📦

Multi-Source Printing

Print labels from Products, Purchase Orders, Manufacturing Orders, Stock Pickings, and Lots. Quantities are pre-filled from document lines and editable before printing.

⚖️

Alternative UoM Support

Switch the label's Unit of Measure using VPA UoM alternative conversions — print carton labels, pack labels, and unit labels from the same template.

📡

RFID Encoding

Encode EPC Gen2 / UHF RFID tags at print time via the ZPL ^RFW command — combine printed content and RFID data on a single label.

📋

Copy & Reuse Elements

Copy elements from one template to another with automatic scaling to the target label size — build new formats in minutes, not hours.

💾

Backup & Restore

Export label templates to a file and restore them on any database — move designs between test and production, or share them across companies.

🏢

Multi-Company & Security

Full multi-company support with record rules, plus dedicated User and Manager access groups to control who designs and who prints.

🔄 How It Works

From Design to Printed Label

Step 1 Define Label Size (mm auto-converted to dots)
Step 2 Design Template on the Visual Canvas
Step 3 Preview the Rendered Label Live
Step 4 Print to Zebra (Network or Browser Print)
