VPA Production Studio - Base

Master BOM with Categories & Material Selection for Odoo 19

Master BOM Templates with BOM Categories

Create flexible Master BOMs with Category + Description + Quantity (without specifying products). Workers select actual materials from category-filtered dropdowns during production. Similar to SAP BOM Groups functionality.

Key Features

BOM Categories

Classify raw materials into categories like Paint, Hardwood, Hinges, Adhesives, etc. Filter products by category during material selection.

Master BOM Templates

Create BOMs with Category + Description + UoM + Qty without specifying exact products. Perfect for flexible manufacturing workflows.

Raw Material Management

Mark products as raw materials and assign BOM categories. Drag-and-drop Kanban view for easy category assignment.

Security & Cost Control

BOM Manager security group controls who can create/edit BOMs. Cost visibility restricted to Accounting users only.

How It Works

  1. Create BOM Categories: Admin creates categories (Paint, Hardwood, Hinges, etc.)
  2. Mark Raw Materials: Products are flagged as raw materials with assigned categories
  3. Create Master BOM: BOM lines have Category + Description + UoM + Qty (no product)
  4. Production: Workers select actual products from category-filtered dropdown in MO
  5. Track Variance: System tracks planned vs actual quantities used
