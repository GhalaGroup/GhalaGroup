Overview

VPA Accounting Internal Transfer is a professional solution for managing internal fund transfers in Odoo Enterprise. Handle bank-to-bank, bank-to-cash, cash-to-bank, and cash-to-cash transfers with configurable multi-level approval workflow, automatic bank statement line creation, and auto-reconciliation.

How It Works

Get started in 3 simple steps

1

Install & Configure

Install: Search for "VPA Accounting Internal Transfer" in Apps

Configure: Set default transfer account in Accounting Settings

Thresholds: Configure approval thresholds by amount

2

Create Transfer

Select Journals: Choose source and destination journals

Enter Amount: Amount with optional multi-currency

Submit: Select approver and submit for approval

3

Approve & Done!

Notification: Approver receives activity notification

Review: Approve or reject with reason

Auto-Post: Bank lines created and reconciled automatically!

Enterprise-Grade Security

Uses standard Odoo accounting security groups

🔐 Access Control

  • Accountant (group_account_user): Create and submit transfers
  • Account Manager (group_account_manager): Approve, reject, cancel transfers
  • Company Rules: Users only see their company's transfers
  • Lock Feature: Lock approved transfers to prevent changes

📋 Audit Features

  • Chatter Integration: All actions logged with timestamps
  • Approval Trail: Who submitted, approved, rejected tracked
  • Cancellation Reason: Required reason for all cancellations
  • Reversal Entries: Proper reversals on cancellation
