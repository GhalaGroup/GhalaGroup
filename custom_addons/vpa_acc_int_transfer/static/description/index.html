Overview

VPA Accounting Internal Transfer is a comprehensive solution for managing internal fund transfers between bank and cash accounts in Odoo. Features multi-level approval workflow, automatic journal entry creation, auto-reconciliation, and complete audit trail. Perfect for businesses requiring proper authorization and accounting controls for internal fund movements.

How It Works

Get started in 3 simple steps

1

Create Transfer

Select Source: Choose source bank/cash journal

Select Destination: Choose destination journal

Enter Amount: Specify transfer amount

Add Memo: Optional description for reference

2

Submit & Approve

Submit: Send for approval

Threshold Check: System determines required approval level

Approve: Manager or Admin approves based on amount

3

Auto-Posted!

Journal Entries: Created automatically

Reconciliation: Transfer account reconciled

Print Voucher: PDF report available

Enterprise-Grade Security

Role-based access control with proper segregation of duties

Security Roles

  • Transfer User: Create and submit transfers, view own transfers
  • Transfer Manager: Approve up to threshold, view all transfers
  • Transfer Administrator: Approve all amounts, configure thresholds, full access

Access Controls

  • Company-Based: Multi-company isolation with record rules
  • Threshold Routing: Automatic approval level based on amount
  • Audit Logging: All actions tracked via chatter
  • Rejection Reasons: Mandatory reason for rejections
