Overview

VPA Accounting Internal Transfer is a professional solution for managing internal fund transfers in Odoo Enterprise. Handle bank-to-bank, bank-to-cash, cash-to-bank, and cash-to-cash transfers with configurable multi-level approval workflow, automatic bank statement line creation, and auto-reconciliation.

Security & Access Control

Uses standard Odoo accounting security groups:

Access Control
  • Accountant: Create and submit transfers
  • Account Manager: Approve, reject, cancel transfers
  • Company Rules: Users only see their company's transfers
  • Lock Feature: Lock approved transfers to prevent changes
 Audit Features
  • Chatter Integration: All actions logged with timestamps
  • Approval Trail: Who submitted, approved, rejected tracked
  • Cancellation Reason: Required reason for all cancellations
  • Reversal Entries: Proper reversals on cancellation
