📋 Overview

VPA - Manufacturing Order Link revolutionizes how you manage Manufacturing Orders in Odoo. This powerful module extends the standard manufacturing integration to provide flexible workflows that adapt to your business needs - whether you need automatic MO creation, manual linking, or support for products without Bills of Materials.

Perfect for manufacturing businesses that require full control over their production process, support pre-production scenarios, or work with custom/engineered products where BOMs are defined after order confirmation.

✨ Key Features

📝

Draft MO Creation

All automatically created MOs stay in DRAFT state, never auto-confirmed. Review quantities, dates, and components before starting production.

🔧

No-BOM Support

Create Manufacturing Orders even when Bill of Materials doesn't exist. Perfect for custom or engineered-to-order products.

🔗

Manual MO Linking

Link pre-created Manufacturing Orders to Sales Orders. Supports make-to-stock and pre-production scenarios seamlessly.

📊

Unified Smart Button

Single "Manufacturing" button displays ALL linked MOs - both automatic and manual. Clean, organized production visibility.

⚙️

Production Route

Dedicated "Production" route created automatically. Product-selectable and compatible with multi-warehouse setups.

🔄

Flexible Workflows

Supports automatic creation, manual linking, pre-production, and custom manufacturing scenarios all in one module.

🔄 Supported Workflows

Workflow 1: Automatic MO Creation

Step 1 Assign Production Route to Product
Step 2 Create & Confirm Sales Order
Step 3 MO Created Automatically (DRAFT)
Step 4 Review & Confirm MO

Workflow 2: Pre-Production Linking

Step 1 Create MO First
Step 2 Set Source = "S01234"
Step 3 Create Sales Order S01234
Step 4 MO Auto-Links to SO

Workflow 3: Manual Link Action

Step 1 Create MO & SO Separately
Step 2 Open SO → Action Menu
Step 3 Click "MO - Link"
Step 4 Link Established
