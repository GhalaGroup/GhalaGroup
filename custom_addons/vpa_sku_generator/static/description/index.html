Product Sequence Generator

Professional SKU Management for Odoo 19

Automate Your Product SKU Generation

Generate professional SKUs automatically based on category hierarchy. Perfect for businesses that need consistent product identification.

Key Features

Auto-Generate SKUs

Automatically generate SKUs based on category hierarchy when creating or updating products. Example: FUR/TBL/00001

SKU Locking & Readonly

Internal Reference is always readonly — SKUs are fully system-managed. Lock individual products to prevent regeneration. Protect your critical products.

Gap Filling

Recycle SKUs from deleted products to eliminate gaps in your numbering sequence. Maintain clean, sequential SKUs.

Variant Support

Automatically handle product variants with sequential suffixes. Format: FUR/TBL/00003-001, 00003-002

How It Works

  1. Set Up Categories: Assign short codes to your product categories (FUR, TBL, CHR)
  2. Configure Settings: Choose validation rules and auto-generation preferences
  3. Create Products: SKUs automatically generate when you select a category
  4. Lock Important Products: Prevent accidental changes to critical SKUs
  5. Regenerate When Needed: Preview and regenerate SKUs in bulk
  6. Recycle Deleted SKUs: System automatically fills gaps

Installation

  1. Install the module from Apps menu
  2. Navigate to Inventory → Configuration → Product Sequence Generator
  3. Set up your category short codes
  4. Configure validation rules and options
  5. Start creating products with automatic SKU generation!
