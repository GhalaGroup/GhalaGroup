Overview

VPA Production Studio - Configurator is a professional product configuration solution for Odoo Enterprise. Quote variable-sized items like doors, cabinets, and wall cladding with dimension-based pricing. Configure options like veneer types, hardware, and finishes — all flowing through to manufacturing with full spec panels.

Key Features

Dimension Templates
Reusable configuration schemas for W×H, W×H×D, diameter, and linear products. Define formulas for area, volume, and linear calculations. 		Configuration Variables
Simple text selections or inventory-product-linked options with BOM category filtering. Group variables into display groups (Door Leaf, Frame, Hardware).
Formula-Based Pricing
Rate per m², m³, or linear meter with product-specific surcharges. Per-unit, per-computed-qty, or fixed amount surcharge types. 		Configurator Popup
Live price preview as sales users enter dimensions and select options. Clean, intuitive wizard interface for fast quoting.
Clean Quotations
Customer sees dimensions and total price. Internal rate and surcharge breakdowns stay hidden on printed quotes. 		MO Integration
Dimensions, configuration selections, and spec panels flow from Sales Order to Manufacturing Order automatically through procurement chains.
BOM Scaling
BOM component quantities scale by computed area or volume. Template placeholders get replaced with actual product selections from configurator. 		Excel Import
Bulk dimension entry from spreadsheets for large orders with many line items. Streamline quoting for high-volume projects.
