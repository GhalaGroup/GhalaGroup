🔄 Conversion Workflow

Expense Conversion Process

  1. Create Request: User selects products, adds photos, specifies expense account
  2. Submit for Approval: Request moves to Manager's queue
  3. Manager Approval: Manager reviews and signs (if within limit)
  4. Admin Verification: Administrator posts the conversion
  5. Automatic Processing:
    • Creates stock adjustment (removes inventory)
    • Generates journal entry (Debit: Expense, Credit: Stock Valuation)
    • Updates inventory values
  6. Document Generation: Professional PDF with all signatures

Asset Conversion Process

  1. Create Request: User selects products, chooses asset category
  2. Configure Depreciation: Set method, duration, start date
  3. Approval Workflow: Manager → Administrator approval
  4. Automatic Processing:
    • Creates stock adjustment (removes from inventory)
    • Generates journal entry (transfers to asset account)
    • Creates fixed asset records automatically
    • Sets up depreciation schedule
  5. Asset Activation: Assets ready for depreciation
