⚙️ Configuration Guide

Complete setup instructions for VPA Inventory Conversion

Quick Start Configuration

Follow this 5-minute setup to get VPA Inventory Conversion ready for use:

  1. Configure document sequences (ASC numbers)
  2. Set up default expense and asset accounts
  3. Configure approval thresholds
  4. Assign user privileges
  5. Create reason templates (optional but recommended)
ℹ️ Pro Tip: Complete all configuration steps before creating your first conversion to ensure smooth operation.

Step 1: Access Configuration Settings

1 Navigate to Settings

Go to Settings → Inventory Conversion (you may need to scroll down in the Settings menu)

[Screenshot: Settings Menu - Inventory Conversion Section]
⚠️ Permissions Required: Only users with "Administrator" access rights can modify these settings. If you don't see the Inventory Conversion section, contact your system administrator.

Step 2: Configure Document Numbering

Sequential Numbering Configuration

VPA Inventory Conversion uses a unified sequence for all conversions with the format: ASC/YYYY/00001

Sequence Settings

Prefix: ASC/%(year)s/ Automatically includes current year
Padding: 5 digits Example: 00001, 00002, etc.
Next Number: 1 (default) Change if needed
Reset Yearly: ✅ Enabled Resets to 00001 each year

Configuration Steps:

  1. In Settings → Inventory Conversion → Document Numbering
  2. Review the default prefix: ASC/%(year)s/
  3. Adjust padding if needed (5 is recommended)
  4. Set "Next Number" if you want to start from a specific number
  5. Save settings

Sequence Examples:

  • ASC/2024/00001 - First conversion in 2024
  • ASC/2024/00002 - Second conversion in 2024
  • ASC/2024/00156 - 156th conversion in 2024
  • ASC/2025/00001 - First conversion in 2025 (resets)
💡 Customization: You can change the prefix to match your company's numbering scheme. For example: IC/%(year)s/ (Inventory Conversion) or INV/%(year)s/.

Reset Sequence (If Needed)

If you need to reset the sequence back to 1:

  1. Go to Settings → Inventory Conversion → Document Numbering
  2. Click "Reset to 1" button
  3. Confirm the action
⚠️ Warning: Resetting the sequence may create duplicate document numbers if you have existing conversions. Only reset if absolutely necessary.

Step 3: Configure Default Accounts

Expense Account Configuration

Set up default accounts for expense conversions to speed up the creation process.

Default Expense Conversion Account

  1. Go to Settings → Inventory Conversion → Default Accounts
  2. Click on "Default Expense Conversion Account" field
  3. Select an expense account from your Chart of Accounts
  4. Recommended accounts:
    • 6xxx - Inventory Loss/Write-off
    • 6xxx - Cost of Goods Sold (COGS)
    • 6xxx - Operating Expenses
  5. Save settings

Common Expense Accounts:

Account Type Typical Code Use Case
Inventory Write-off 6100 Damaged, obsolete, expired goods
Cost of Goods Sold 5000 Direct inventory costs
Loss on Inventory 6200 Theft, shrinkage, damage
Operating Expense 6500 General operational losses

Asset Account Configuration

Default Asset Conversion Account

  1. Go to Settings → Inventory Conversion → Default Accounts
  2. Click on "Default Asset Conversion Account" field
  3. Select a fixed asset account from Chart of Accounts
  4. Typical accounts:
    • 1500 - Fixed Assets
    • 1510 - Furniture & Equipment
    • 1520 - Machinery & Tools
  5. Save settings
💡 Note: Users can override these default accounts when creating conversions. These defaults simply speed up data entry.

Step 4: Configure Approval Thresholds

Approval Workflow Settings

Define dollar amount thresholds that determine which approval level is required.

Approval Threshold Configuration

  1. Go to Settings → Inventory Conversion → Approval Thresholds
  2. Set the following thresholds:
    Setting Recommended Value Description
    Auto-approve below $0 (disabled) Amount below which conversions auto-approve
    Manager approval limit $50,000 Max amount Managers can approve
    Dual approval above $100,000 Requires Admin + secondary approval
  3. Save settings

Example Approval Matrix:

Conversion Value Required Approval Level Workflow
$0 - $5,000 Manager User → Manager → Post
$5,001 - $50,000 Manager User → Manager → Admin → Post
$50,001 - $100,000 Administrator User → Admin → Post
Over $100,000 Dual Approval User → Admin + Secondary → Post

Additional Workflow Options

Notification Settings

  • ☑️ Send notification to approvers - Email alerts when approval needed
  • ☑️ Lock conversions after posting - Prevent editing posted records
  • ☑️ Require reason for all conversions - Mandatory reason field
  • ☐ Allow self-approval - Let users approve their own requests (not recommended)

Step 5: Configure Email Notifications

Email Template Configuration

VPA Inventory Conversion sends automatic email notifications at key workflow stages.

Default Email Triggers:

Trigger Recipient Template
Conversion Submitted Manager Approval Request Email
Manager Approved Administrator Admin Verification Needed
Conversion Posted Original User Conversion Complete
Conversion Rejected Original User Rejection Notice
High Value (>$50k) Administrator High Value Alert

Customize Email Templates (Optional):

  1. Go to Settings → Technical → Email → Templates
  2. Search for "VPA Inventory Conversion"
  3. Select the template to customize
  4. Edit subject, body, and recipients as needed
  5. Save changes
⚠️ Important: Ensure your Odoo email server is properly configured (Settings → Technical → Email → Outgoing Mail Servers) for notifications to work.

Step 6: Create Reason Templates

Predefined Reason Templates

Create templates for common conversion reasons to ensure consistency and speed up data entry.

Creating Reason Templates:

  1. Go to Inventory → Configuration → Reason Templates
  2. Click Create
  3. Fill in template details:
    • Name: Short description (e.g., "Damaged During Handling")
    • Description: Full explanation
    • Conversion Type: Expense or Asset
    • Default Account: Associated account (optional)
  4. Save the template

Recommended Templates:

Expense Conversion Templates

Template Name Description Use Case
Damaged - Handling Items damaged during warehouse operations Forklift damage, drops, breaks
Obsolete - No Demand Products no longer sellable or needed Old models, discontinued items
Defective - Manufacturing Products with manufacturing defects Quality failures, production errors
Expired - Shelf Life Items past expiration date Food, chemicals, time-sensitive goods
Customer Return - Damaged Returned products not resalable Damaged returns, used items
Theft/Loss Missing inventory or stolen goods Shrinkage, theft, loss

Asset Conversion Templates

Template Name Description Use Case
Equipment - Capitalization Convert equipment inventory to fixed asset Tools, machinery put into service
Furniture - Office Use Convert furniture to company asset Desks, chairs, cabinets
IT Equipment - In Use Computers and IT hardware in service Servers, computers, network gear
Vehicle - Fleet Addition Add vehicle to company fleet Trucks, forklifts, company cars

Step 7: Configure Analytic Accounting (Optional)

Department & Cost Center Tracking

If you want to track conversions by department or project:

  1. Ensure Analytic Accounting is enabled:
    • Go to Settings → Accounting → Analytics
    • Enable "Analytic Accounting"
  2. Create Analytic Accounts:
    • Go to Accounting → Configuration → Analytic Accounts
    • Create accounts for each department or cost center
  3. Users can select these when creating conversions
💡 Benefit: Track which departments are generating the most write-offs or asset conversions for better cost control.

Step 8: Multi-Company Setup (If Applicable)

Multi-Company Configuration

If you operate multiple companies in Odoo:

  1. Configure sequences per company:
    • Each company can have different numbering schemes
    • Example: Company A = ASC-A/2024/00001, Company B = ASC-B/2024/00001
  2. Set default accounts per company:
    • Each company can have different expense/asset accounts
  3. Configure approval limits per company:
    • Different threshold amounts for different companies
⚠️ Access Control: Users can only see conversions for companies they have access to, as defined by their user settings.

✓ Default asset account set ☐ Yes (if using assets)
