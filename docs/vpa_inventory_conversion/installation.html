📦 Installation Guide

Step-by-step instructions to install VPA Inventory Conversion

Prerequisites

⚠️ Important: Before installing, ensure you meet all prerequisites to avoid installation issues.

System Requirements

Requirement Specification Status
Odoo Version 19.0 Enterprise Edition Required
Python 3.10 or higher Required
PostgreSQL 12 or higher Required
Disk Space 50 MB minimum Required

Required Odoo Modules

These modules must be installed before VPA Inventory Conversion:

  • account_accountant - Accounting features
  • stock - Inventory management
  • account_asset - Asset management (Enterprise)

Optional Modules (Recommended)

  • purchase - For purchase-related conversions
  • sale_management - For sales integration
  • hr - For department tracking

Installation Methods

Method 1: Install from Apps (Recommended)

1 Navigate to Apps

Log in to your Odoo instance as an administrator and go to the Apps menu.

[Screenshot: Odoo Apps Menu]

2 Search for Module

In the search box, type "VPA Inventory Conversion" and press Enter.

Search: VPA Inventory Conversion

3 Click Install

Locate the module card and click the "Install" button.

[Screenshot: Module Install Button]
ℹ️ Installation Time: The module typically takes 30-60 seconds to install. You'll see a progress indicator during installation.

4 Verify Installation

After installation, verify the module appears in your main menu:

  • Go to Inventory → Operations → Inventory Conversion
  • You should see the conversion dashboard

Method 2: Manual Installation

⚠️ Advanced Users Only: Manual installation requires command-line access and technical knowledge.

1 Download Module

Download the module ZIP file from Odoo Apps Store or your provided link.

2 Extract to Addons Directory

Extract the module to your Odoo custom addons directory:

cd /path/to/odoo/custom_addons
unzip vpa_inventory_conversion.zip

3 Set Permissions

Ensure proper file permissions:

sudo chown -R odoo:odoo vpa_inventory_conversion
sudo chmod -R 755 vpa_inventory_conversion

4 Update Apps List

Restart Odoo server and update the apps list:

# Restart Odoo
sudo systemctl restart odoo

# Update apps list from Odoo UI
# Settings → Technical → Apps → Update Apps List

5 Install Module

Search for "vpa_inventory_conversion" in Apps and click Install.

Method 3: Using Odoo.sh

1 Access Odoo.sh Dashboard

Log in to your Odoo.sh project dashboard.

2 Upload Module

Use the Odoo.sh interface to upload the module ZIP file or add it via Git.

3 Deploy

Deploy the changes to your production or staging branch.

4 Install from Apps

Navigate to Apps and install "VPA Inventory Conversion".

Post-Installation Verification

Checklist

  • Module appears in Apps list with "Installed" status
  • Menu item "Inventory Conversion" visible under Inventory → Operations
  • No error messages in Odoo server logs
  • Settings page accessible at Settings → Inventory Conversion
  • User groups created: User, Manager, Administrator
  • Document sequences initialized (ASC/2024/00001)

Test Installation

  1. Navigate to Inventory → Operations → Inventory Conversion
  2. Click "Create" button
  3. You should see the conversion form without errors
  4. Cancel the form (don't save)
✅ Success! If you can access the conversion form, the module is installed correctly.

Troubleshooting

Common Issues & Solutions

Issue: Module Not Found in Apps

Symptoms: Cannot find "VPA Inventory Conversion" in Apps search

Solutions:

  • Click "Update Apps List" in Apps menu (may require debug mode)
  • Clear browser cache and refresh
  • Verify module is in correct addons directory
  • Check Odoo server logs for loading errors

Issue: Installation Fails

Symptoms: Installation error or module in "To Install" state

Solutions:

  • Check that all required modules are installed first
  • Review Odoo logs: sudo tail -f /var/log/odoo/odoo-server.log
  • Ensure database user has proper permissions
  • Try installing in Odoo debug mode for detailed errors

Issue: Menu Not Visible

Symptoms: Module installed but menu item missing

Solutions:

  • Log out and log back in
  • Verify user has access rights (must be in Inventory/User group minimum)
  • Check if menu is under Inventory → Operations
  • Refresh browser (Ctrl+F5 / Cmd+Shift+R)

Issue: Dependency Error

Symptoms: Error about missing module dependencies

Solutions:

  1. Install account_accountant module
  2. Ensure stock module is installed
  3. Install account_asset (Enterprise required)
  4. Retry VPA Inventory Conversion installation

Upgrade Instructions

Upgrading from Previous Version

⚠️ Backup First: Always backup your database before upgrading!
  1. Backup Database 
    pg_dump your_database_name > backup_before_upgrade.sql
  2. Download New Version - Get the latest module version
  3. Replace Module Files - Overwrite old files with new ones
  4. Restart Odoo 
    sudo systemctl restart odoo
  5. Upgrade Module - Go to Apps → VPA Inventory Conversion → Upgrade
  6. Test Functionality - Verify existing data and features work
ℹ️ Data Safety: Upgrades preserve all existing conversion records, photos, and configurations.

Uninstallation

⚠️ Warning: Uninstalling will permanently delete all conversion records, photos, and configuration data. This action cannot be undone!

Before Uninstalling

  • Export all conversion reports you need to keep
  • Download all attached photos and documents
  • Verify no conversions are in "Posted" state (or reverse them)
  • Backup database

Uninstall Steps

  1. Go to Apps
  2. Search for "VPA Inventory Conversion"
  3. Click the ⋮ (three dots) menu
  4. Select Uninstall
  5. Confirm the action
ℹ️ Note: Uninstalling does NOT reverse journal entries or delete created assets. These remain in your accounting records for audit compliance.
