🔐 Security & User Privileges

Complete guide to access control and user permissions

Overview of Security Model

VPA Inventory Conversion uses a 3-tier privilege system that controls what users can see and do:

👤 User

  • ✓ Create requests
  • ✓ View own conversions
  • ✓ Attach photos
  • ✗ Cannot approve
  • ✗ Cannot post

👨‍💼 Manager

  • ✓ All User permissions
  • ✓ Approve conversions
  • ✓ View all company conversions
  • ✓ Approval limit: $50,000
  • ✗ Cannot post

👨‍💻 Administrator

  • ✓ All Manager permissions
  • ✓ Post conversions
  • ✓ Reverse conversions
  • ✓ Delete conversions
  • ✓ Configure settings

User Group Setup

Assigning Users to Groups

To assign a user to an Inventory Conversion privilege level:

  1. Go to Settings → Users & Companies → Users
  2. Select the user to configure
  3. Click Edit
  4. Scroll to Inventory Conversion section (under Access Rights)
  5. Select the appropriate privilege level:
    • ⭕ User - Can only create requests
    • ⭕ Manager - Can approve conversions
    • ⭕ Administrator - Full control
  6. Save the user
[Screenshot: User Access Rights - Inventory Conversion Section]
⚠️ Important: Users also need basic Inventory/User rights to access inventory data. VPA Inventory Conversion groups automatically grant this.

Approval Limits Configuration

Setting User-Specific Approval Limits

Each Manager can have a custom approval limit. Conversions above this limit require Administrator approval.

Configuring Approval Limits

  1. Go to Settings → Users & Companies → Users
  2. Select a Manager user
  3. Click Edit
  4. Find Inventory Conversion Settings section
  5. Set Approval Limit (e.g., $25,000)
  6. Save the user

Approval Limit Examples

User Role Approval Limit What They Can Approve
John (Warehouse Manager) Manager $10,000 Conversions up to $10,000
Sarah (Operations Manager) Manager $50,000 Conversions up to $50,000
Mike (CFO) Administrator Unlimited Any amount
⚠️ Escalation: If a Manager tries to approve a conversion above their limit, they'll see an error message and the conversion will be escalated to an Administrator.

Data Visibility Rules

What Users Can See

User (Basic Access)

Can See:

  • Only conversions they created
  • Their own conversion history
  • Their submitted requests

Cannot See:

  • Other users' conversions
  • Company-wide analytics
  • Settings or configuration

Manager (Department/Company Access)

Can See:

  • All conversions in their company
  • Pending approvals for the company
  • Department analytics
  • Conversion history and reports

Cannot See:

  • System configuration settings
  • User privilege settings

Administrator (Full Access)

Can See:

  • Everything - all conversions, all companies
  • All analytics and reports
  • System configuration
  • User settings and limits
  • Audit logs and history

Digital Signature Settings

User Signature Configuration

Users who will approve conversions should configure their digital signature:

  1. Click on your User Name (top right) → My Profile
  2. Click Edit
  3. Scroll to Inventory Conversion section
  4. Upload your Digital Signature:
    • Draw signature using mouse/touch
    • Upload image file (PNG, JPG)
    • Recommended size: 300x100 pixels
  5. Save your profile
✅ Benefit: Once saved, your signature will auto-fill when approving conversions, speeding up the approval process.

Multi-Company Security

Company-Based Access Control

In multi-company environments, users can only access conversions for companies they're assigned to:

Company Assignment

  1. Go to Settings → Users & Companies → Users
  2. Select a user
  3. Under Multi Companies, assign allowed companies
  4. User will only see conversions for those companies

Cross-Company Rules

  • Users cannot approve conversions from companies they don't have access to
  • Administrators can be granted access to all companies
  • Reports filter automatically by user's allowed companies

Security Best Practices

Recommended User Setup

Small Business (5-20 employees)

  • Users: Warehouse staff, inventory clerks
  • Manager: 1-2 department heads ($10,000 limit)
  • Administrator: Owner, CFO, or controller

Medium Business (20-100 employees)

  • Users: All warehouse and inventory staff
  • Managers: Department managers ($25,000-$50,000 limits)
  • Administrators: CFO, Finance Director, IT Manager

Large Enterprise (100+ employees)

  • Users: Front-line staff at multiple locations
  • Managers: Site managers, department heads (tiered limits: $10K, $25K, $50K)
  • Administrators: Finance team, regional controllers
  • Custom approval routing based on location and value

Security Guidelines

🔒 Important Security Rules:
  • Never give Administrator access to users who don't need it
  • Review approval limits quarterly
  • Require strong passwords for all users
  • Enable two-factor authentication for Administrators
  • Regularly audit who has Manager/Administrator access
  • Disable accounts for former employees immediately
  • Don't allow self-approval (user approves own conversion)

Troubleshooting Access Issues

Common Problems & Solutions

Problem: User can't see Inventory Conversion menu

Solution:

  • Verify user has at least "User" privilege in Inventory Conversion
  • Check that user has basic "Inventory/User" rights
  • Log out and log back in
  • Clear browser cache

Problem: Manager can't approve conversion

Solution:

  • Check the conversion value vs. Manager's approval limit
  • Verify Manager has correct privilege level
  • Ensure conversion is in "Waiting Approval" state
  • Check if conversion belongs to Manager's company

Problem: User can see other users' conversions

Solution:

  • This is normal for Managers and Administrators
  • If the user should be restricted, change their privilege to "User"
  • Verify record rules are active (contact system administrator)
