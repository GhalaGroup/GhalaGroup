Module 8: vpa_furniture_nesting

CNC Sheet Cutting Optimization & Material Waste Reduction

Phase: Phase 3 Type: Manufacturing Status: Furniture-Specific Price: $10,000

Overview

vpa_furniture_nesting provides advanced CNC cutting optimization for sheet materials (MDF, plywood, veneer). The module arranges furniture components on standard sheet sizes to minimize waste, generates DXF/SVG files for CNC machines, and tracks material utilization with real-time waste reporting.

Why This Matters: Material waste is one of the largest costs in furniture manufacturing. Nesting optimization can reduce waste from 15-20% down to 5-8%, saving thousands of dollars monthly. A single optimized cutting plan can save $50-200 per sheet.
$10,000

Technical Architecture

Nesting Engine

class NestingProject(models.Model): """CNC nesting project for manufacturing order""" _name = 'furniture.nesting.project' name = fields.Char('Project Name') manufacturing_order_id = fields.Many2one('mrp.production') sheet_material_id = fields.Many2one( 'product.product', string='Sheet Material', domain="[('is_sheet_material', '=', True)]" ) sheet_width = fields.Float('Sheet Width (mm)', default=2440.0) sheet_height = fields.Float('Sheet Height (mm)', default=1220.0) sheet_thickness = fields.Float('Thickness (mm)') component_ids = fields.One2many( 'furniture.nesting.component', 'project_id', string='Components to Nest' ) sheet_ids = fields.One2many( 'furniture.nesting.sheet', 'project_id', string='Cutting Sheets' ) total_waste_percentage = fields.Float( compute='_compute_waste', string='Waste %' ) def action_run_nesting(self): """Execute nesting algorithm""" self.ensure_one() # Prepare components components = self._prepare_components() # Run 2D bin packing algorithm sheets = self._nest_components(components) # Create sheet records self._create_sheets(sheets) # Generate cutting files self._generate_dxf_files() def _nest_components(self, components): """ 2D Bin Packing Algorithm: 1. Sort components by area (largest first) 2. Try to fit each component into current sheet 3. Use best-fit strategy (tightest space) 4. Respect grain direction constraints 5. Add cutting margins (blade kerf) """ sheets = [] current_sheet = self._new_sheet() for component in sorted(components, key=lambda c: c.area, reverse=True): position = self._find_best_position(current_sheet, component) if position: current_sheet.place_component(component, position) else: # Component doesn't fit, start new sheet sheets.append(current_sheet) current_sheet = self._new_sheet() current_sheet.place_component(component, (0, 0)) sheets.append(current_sheet) return sheets

Nesting Component

class NestingComponent(models.Model): """Individual furniture component to be cut""" _name = 'furniture.nesting.component' project_id = fields.Many2one('furniture.nesting.project') bom_line_id = fields.Many2one('mrp.bom.line') name = fields.Char('Component Name') width = fields.Float('Width (mm)', required=True) height = fields.Float('Height (mm)', required=True) quantity = fields.Integer('Quantity', default=1) grain_direction = fields.Selection([ ('none', 'No Preference'), ('horizontal', 'Horizontal Only'), ('vertical', 'Vertical Only'), ], default='none') area = fields.Float( compute='_compute_area', string='Area (mm²)' ) edge_banding = fields.Selection([ ('none', 'None'), ('two_sides', 'Two Sides'), ('four_sides', 'Four Sides'), ]) @api.depends('width', 'height', 'quantity') def _compute_area(self): for comp in self: comp.area = comp.width * comp.height * comp.quantity

DXF Export

import ezdxf def _generate_dxf_files(self): """Generate DXF cutting files for CNC""" for sheet in self.sheet_ids: # Create new DXF document doc = ezdxf.new('R2010') msp = doc.modelspace() # Draw sheet outline msp.add_lwpolyline([ (0, 0), (sheet.width, 0), (sheet.width, sheet.height), (0, sheet.height), (0, 0) ], close=True) # Draw each component for placement in sheet.placement_ids: x = placement.position_x y = placement.position_y w = placement.component_id.width h = placement.component_id.height # Add rectangle for component msp.add_lwpolyline([ (x, y), (x + w, y), (x + w, y + h), (x, y + h), (x, y) ], close=True) # Add label text msp.add_text( placement.component_id.name, dxfattribs={ 'insert': (x + 10, y + 10), 'height': 50 } ) # Save DXF file filename = f'nest_{sheet.name}.dxf' doc.saveas(filename) sheet.dxf_file = base64.b64encode(open(filename, 'rb').read())

Installation & Configuration

Prerequisites

  • Module 1: vpa_furniture_studio
  • Module 6: vpa_furniture_manufacturing
  • Python libraries: ezdxf, svgwrite
  • CNC machine with DXF import capability

Setup Steps

  1. Define Sheet Materials: Create product records for standard sheets
  2. Set Cutting Margins: Configure blade kerf (typically 3-5mm)
  3. Configure Grain Rules: Define which components require grain direction
  4. Test Nesting: Run test project with sample components
  5. CNC Integration: Test DXF file import on CNC machine
Best Practices:
  • Always add 5mm margin for blade kerf
  • Group similar thickness components together
  • Respect grain direction for visible surfaces
  • Save cutting files with clear naming: MO-001_Sheet1.dxf
