Module 6: vpa_furniture_manufacturing

Furniture-Specific Manufacturing & Production Orders

Phase: Phase 1 Type: Manufacturing Status: Furniture-Specific Price: $8,000

Overview

vpa_furniture_manufacturing extends Odoo's manufacturing module with furniture-specific production workflows. This module enables make-to-order manufacturing, automatically creates manufacturing orders from sales orders, manages work centers for furniture assembly, and handles furniture-specific routing.

Why This Matters: Custom furniture is predominantly make-to-order (MTO). This module automates the transition from sales to production, ensuring every configured order triggers the right manufacturing processes without manual intervention.
$8,000

Key Features

Make-to-Order (MTO)
Automatically create MOs when sales orders are confirmed
Furniture Work Centers
Pre-configured for cutting, assembly, finishing, upholstery
Smart Routing
Furniture-specific production routes (door vs cabinet vs desk)
BOM Integration
Consumes materials from configurator BOMs
Work Order Tracking
Track progress at each production stage
Component Production
Create sub-assemblies (frames, panels, drawers)

Manufacturing Order Extensions

class FurnitureManufacturingOrder(models.Model): """Extends mrp.production with furniture-specific fields""" _inherit = 'mrp.production' # Furniture-specific fields furniture_type = fields.Selection( related='product_id.furniture_type', string='Furniture Type', store=True ) furniture_dimensions = fields.Char( compute='_compute_furniture_dimensions', string='Dimensions (H×W×D)' ) sale_order_id = fields.Many2one( 'sale.order', string='Sales Order', compute='_compute_sale_order', store=True ) customer_id = fields.Many2one( related='sale_order_id.partner_id', string='Customer', store=True ) custom_finish = fields.Char('Custom Finish') custom_notes = fields.Text('Production Notes') @api.depends('product_id') def _compute_furniture_dimensions(self): for mo in self: if mo.product_id.is_furniture: h = mo.product_id.furniture_height w = mo.product_id.furniture_width d = mo.product_id.furniture_depth mo.furniture_dimensions = f"H{h}×W{w}×D{d}mm" else: mo.furniture_dimensions = False def action_confirm(self): """Override to add furniture-specific logic""" res = super().action_confirm() # Auto-assign to furniture work center based on type for mo in self: if mo.furniture_type: mo._assign_furniture_workcenter() return res

Production Workflow

Make-to-Order Process

  1. Sales Order Confirmed: Customer places order for "Quadroto Desk W1600×D750 - Walnut"
  2. MO Auto-Created: System creates Manufacturing Order automatically
  3. BOM Consumed: Materials reserved from configurator BOM
  4. Work Orders Generated: Operations created based on routing
  5. Production Started: Shop floor begins work
  6. Components Tracked: Each operation marked complete
  7. Final Product: Desk moves to warehouse for delivery

Installation & Configuration

Prerequisites

  • Module 1: vpa_furniture_studio (BASE) installed
  • Odoo Manufacturing module enabled
  • Work centers configured
  • Product BOMs created (manually or from configurator)

Post-Installation Setup

  1. Configure Work Centers: Navigate to Manufacturing → Configuration → Work Centers
  2. Set Product Routes: Enable "Manufacture" route on furniture products
  3. Create Routing Templates: Define standard operations for furniture types
  4. Test MTO Flow: Create test sales order and verify MO creation
  5. Train Production Team: Educate staff on work order interface
Recommended Combo: This module works best with:
  • Module 2: Configurator (auto-generate BOMs)
  • Module 7: Smart BOMs (material substitution)
  • Module 12: Shop Floor (tablet interface for operators)
