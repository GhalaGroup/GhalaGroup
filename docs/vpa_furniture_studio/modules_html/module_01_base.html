Module 1: vpa_furniture_studio

Foundation Module - Required by ALL

📦 Phase: Phase 1 🏷️ Type: Core Foundation ✅ Status: Required 💰 Price: $2,000

Overview

vpa_furniture_studio (BASE) is the foundation module that provides essential furniture-specific functionality required by all other VPA modules. It extends Odoo's core product and inventory models with dimension management, furniture types, and specialized unit of measure handling.

✅ Why This Matters: This module establishes the fundamental data structures that make VPA Furniture Studio uniquely suited for custom furniture manufacturing. Without it, none of the advanced features (configuration, costing, manufacturing, etc.) can function properly.
$2,000

Key Features

📏 Dimension Management
Track Height × Width × Depth for all furniture products
🪑 Furniture Types
Categorize products (Door, Cabinet, Desk, Table, Chair, etc.)
📐 UOM Handling
Support for m², m³, linear meters, and piece
🧮 Auto-Calculate
Automatically compute areas and volumes from dimensions
🎨 Product Extensions
Extends product.template with furniture-specific fields
🔧 Configuration Base
Foundation for configurator and BOM systems

Technical Specifications

Database Models

class FurnitureProduct(models.Model): """Extends product.template with furniture-specific fields""" _inherit = 'product.template' # Furniture Identification is_furniture = fields.Boolean('Is Furniture Product') furniture_type = fields.Selection([ ('door', 'Door'), ('cabinet', 'Cabinet'), ('desk', 'Desk'), ('table', 'Table'), ('chair', 'Chair'), ('shelf', 'Shelf'), ('panel', 'Panel'), ('workstation', 'Workstation'), ], string='Furniture Type') # Dimensions (in mm) furniture_height = fields.Float('Height (mm)', default=750.0) furniture_width = fields.Float('Width (mm)') furniture_depth = fields.Float('Depth (mm)') # Computed Measurements area_m2 = fields.Float( 'Area (m²)', compute='_compute_area', store=True ) volume_m3 = fields.Float( 'Volume (m³)', compute='_compute_volume', store=True ) perimeter_m = fields.Float( 'Perimeter (m)', compute='_compute_perimeter', store=True ) @api.depends('furniture_width', 'furniture_depth') def _compute_area(self): """Calculate area in square meters""" for record in self: if record.furniture_width and record.furniture_depth: # Convert mm to m and calculate width_m = record.furniture_width / 1000.0 depth_m = record.furniture_depth / 1000.0 record.area_m2 = width_m * depth_m else: record.area_m2 = 0.0 @api.depends('furniture_width', 'furniture_depth', 'furniture_height') def _compute_volume(self): """Calculate volume in cubic meters""" for record in self: if record.furniture_width and record.furniture_depth and record.furniture_height: # Convert mm to m and calculate width_m = record.furniture_width / 1000.0 depth_m = record.furniture_depth / 1000.0 height_m = record.furniture_height / 1000.0 record.volume_m3 = width_m * depth_m * height_m else: record.volume_m3 = 0.0

Use Cases & Examples

Example 1: Creating a Door Product

# Create a door product door = env['product.template'].create({ 'name': 'Veneer Door - Walnut', 'is_furniture': True, 'furniture_type': 'door', 'furniture_height': 2200.0, # mm 'furniture_width': 900.0, # mm 'furniture_depth': 40.0, # mm 'uom_id': env.ref('uom.product_uom_unit').id, }) # Automatically computed: # door.area_m2 = 1.98 m² # door.volume_m3 = 0.0792 m³

Example 2: Office Desk with Multiple Sizes

# Create desk family with variants desk_sizes = [ (1200, 750), # W1200 × D750 (1400, 750), # W1400 × D750 (1600, 750), # W1600 × D750 (1800, 750), # W1800 × D750 ] for width, depth in desk_sizes: env['product.template'].create({ 'name': f'Quadroto Office Desk W{width}×D{depth}', 'is_furniture': True, 'furniture_type': 'desk', 'furniture_height': 750.0, 'furniture_width': float(width), 'furniture_depth': float(depth), })

Installation & Configuration

Installation

  1. Ensure Odoo 19 Enterprise is installed
  2. Copy module to addons directory
  3. Update apps list
  4. Install vpa_furniture_studio module
  5. No configuration required - ready to use!

Post-Installation

After installation:

  • Navigate to Inventory → Products
  • Create or edit a product
  • Check the "Is Furniture Product" checkbox
  • New "Furniture" tab appears with dimension fields
  • Enter dimensions and type
  • Areas and volumes calculate automatically
