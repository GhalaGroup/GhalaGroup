💰 Module 4: vpa_furniture_costing

Advanced Historical Cost Tracking & Profitability Analysis

📦 Phase: Phase 1 (Months 1-6) 🏷️ Type: Costing & Reporting ⚡ Priority: High $7,000

📋 Overview

The vpa_furniture_costing module provides historical cost tracking using weighted averages from actual production data. Unlike traditional systems that rely on fixed estimates, this module tracks real costs and automatically updates profitability metrics.

🔥 Critical Innovation: This system uses actual production costs (not estimates) to calculate weighted averages, giving you the most accurate profitability data possible.

📊 Historical Cost Tracking

Weighted average costs from actual production runs

💹 Real-Time Profitability

Instant profit margin calculation on every order

🔍 Cost Breakdown

Detailed analysis: materials, labor, overhead

📈 Trend Analysis

Cost trends over time with variance reports

🎯 Key Features

1. Historical Cost Calculation

# How Weighted Average Works:
Production Run 1: Door - Materials: $45, Labor: $15, Total: $60
Production Run 2: Door - Materials: $48, Labor: $14, Total: $62
Production Run 3: Door - Materials: $46, Labor: $16, Total: $62

Weighted Average Cost = (60 + 62 + 62) / 3 = $61.33

When Production Run 4 completes, system automatically recalculates:
Weighted Average Cost = (60 + 62 + 62 + 64) / 4 = $62.00
💡 Why This Matters: Fixed estimates become outdated. Weighted averages from actual production give you real-time insight into true costs and profitability.

2. Cost Components

Cost Component How Calculated Source
Material Cost Sum of all materials consumed Stock moves from MO
Labor Cost Actual time × hourly rate per operation Work order time tracking
Overhead % of material + labor (configurable) Company overhead rate
Waste/Scrap Materials marked as scrap Scrap orders
Rework Additional time/materials from quality failures Quality control module

  • Order-Level Profit: Actual profit/margin per sales order
  • Product-Level Profit: Average profitability per product type
  • Customer-Level Profit: Total profitability per customer
  • Material-Level Cost: Trends in material costs over time
  • Labor Efficiency: Actual vs. standard labor costs

🔧 Technical Architecture

Historical Cost Model

class FurnitureProductionCost(models.Model):
    _name = 'furniture.production.cost'
    _description = 'Historical Production Cost Record'

    production_id = fields.Many2one('mrp.production', 'Manufacturing Order')
    product_id = fields.Many2one('product.product', 'Product', required=True)

    # Cost Breakdown
    material_cost = fields.Monetary('Material Cost', currency_field='currency_id')
    labor_cost = fields.Monetary('Labor Cost', currency_field='currency_id')
    overhead_cost = fields.Monetary('Overhead Cost', currency_field='currency_id')
    waste_cost = fields.Monetary('Waste/Scrap Cost', currency_field='currency_id')
    rework_cost = fields.Monetary('Rework Cost', currency_field='currency_id')
    total_cost = fields.Monetary('Total Cost', compute='_compute_total_cost', store=True)

    # Quantity
    qty_produced = fields.Float('Quantity Produced', default=1.0)
    unit_cost = fields.Monetary('Unit Cost', compute='_compute_unit_cost', store=True)

    # Metadata
    date_produced = fields.Datetime('Production Date', default=fields.Datetime.now)
    currency_id = fields.Many2one('res.currency', related='company_id.currency_id')

    @api.depends('material_cost', 'labor_cost', 'overhead_cost', 'waste_cost', 'rework_cost')
    def _compute_total_cost(self):
        for rec in self:
            rec.total_cost = (rec.material_cost + rec.labor_cost +
                             rec.overhead_cost + rec.waste_cost + rec.rework_cost)

    @api.depends('total_cost', 'qty_produced')
    def _compute_unit_cost(self):
        for rec in self:
            rec.unit_cost = rec.total_cost / rec.qty_produced if rec.qty_produced else 0.0

Weighted Average Calculation

class ProductTemplate(models.Model):
    _inherit = 'product.template'

    # Historical Cost Fields
    weighted_avg_cost = fields.Monetary('Weighted Avg Cost',
        compute='_compute_weighted_avg_cost', store=True,
        currency_field='currency_id')

    historical_cost_count = fields.Integer('Cost Records Count',
        compute='_compute_historical_costs')

    last_production_cost = fields.Monetary('Last Production Cost',
        compute='_compute_historical_costs',
        currency_field='currency_id')

    @api.depends('furniture_production_cost_ids.unit_cost')
    def _compute_weighted_avg_cost(self):
        for product in self:
            cost_records = product.furniture_production_cost_ids.filtered(
                lambda r: r.date_produced >= (fields.Datetime.now() - timedelta(days=90))
            )
            if cost_records:
                total_cost = sum(cost_records.mapped('total_cost'))
                total_qty = sum(cost_records.mapped('qty_produced'))
                product.weighted_avg_cost = total_cost / total_qty if total_qty else 0.0
            else:
                product.weighted_avg_cost = product.standard_price
