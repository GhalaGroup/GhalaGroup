🎨 Module 2: vpa_furniture_configurator

Dynamic Product Configuration System with BOM Groups

📦 Phase: Phase 1 (Months 1-6) 🏷️ Type: Sales & Configuration ⚡ Priority: High $6,000

📋 Overview

The vpa_furniture_configurator module enables dynamic furniture product configuration using BOM Groups architecture. This revolutionary approach eliminates hardcoded material options and allows real-time material selection from inventory categories.

💡 Key Innovation: Unlike traditional configurators that hardcode material choices, this system queries inventory dynamically. When a customer selects "Oak Veneer", the system finds all oak veneer products in inventory automatically from the product.category structure.

🎯 BOM Groups Architecture

Category-based material selection that adapts to your inventory

📐 Dimension-Based Config

Height × Width × Depth configuration wizard

🔄 Real-Time Validation

Stock availability and technical constraint checking

💰 Auto-Pricing

Automatic price calculation from actual inventory costs

🎯 Key Features

1. BOM Groups System

The revolutionary architecture that makes this module unique:

BOM Group: "Veneer Materials"
├── Category Link: product.category("Veneers")
├── Selection Rule: is_veneer = True
└── Material Options (Auto-Generated):
    ├── Oak Veneer (from inventory)
    ├── Walnut Veneer (from inventory)
    ├── Mahogany Veneer (from inventory)
    └── Cherry Veneer (from inventory)
✅ Advantage: When you add new veneer products to inventory under the "Veneers" category, they automatically appear as configuration options. No code changes required!

2. Product Configuration Wizard

  • Step 1: Select base product type (Door, Cabinet, Desk, etc.)
  • Step 2: Define dimensions (Height, Width, Depth)
  • Step 3: Choose materials from BOM Groups (Veneer, Edge Banding, Hardware)
  • Step 4: Select finishing options (Paint, Stain, Polish)
  • Step 5: Review & add to quote/order

3. Dynamic Material Selection

BOM Group Linked Category Filter Rules Auto-Generated Options
Veneer Materials product.category("Veneers") is_veneer = True Oak, Walnut, Mahogany, Cherry, etc.
Edge Banding product.category("Edge Bands") is_edge_banding = True PVC, ABS, Veneer Edge Bands
Hardware - Hinges product.category("Hardware/Hinges") hardware_type = 'hinge' Concealed, Overlay, Inset Hinges
Hardware - Handles product.category("Hardware/Handles") hardware_type = 'handle' Modern, Classic, Bar Handles

4. Pricing Calculation

Automatic price calculation based on:

  • Material costs from inventory (real-time standard price)
  • Labor cost per product type (from BASE module configuration)
  • Area/volume-based pricing (m² or m³)
  • Quantity discounts (configurable threshold rules)
  • Currency rounding rules (TZS to 1,000; USD/EUR to whole units)

5. Technical Constraints

⚠️ Validation Rules: System validates dimensions against technical constraints (min/max height, width ratios, material thickness compatibility) before allowing configuration.

🔧 Technical Architecture

Database Models

BOM Group Model

class FurnitureBOMGroup(models.Model):
    _name = 'furniture.bom.group'
    _description = 'BOM Group for Dynamic Material Selection'

    name = fields.Char('Group Name', required=True)
    # Example: "Veneer Materials", "Edge Banding", "Hardware - Hinges"

    category_id = fields.Many2one('product.category', 'Material Category', required=True)
    # Links to inventory category (e.g., "Veneers", "Edge Bands")

    filter_domain = fields.Char('Filter Domain',
        help="Domain filter for products (e.g., [('is_veneer', '=', True)])")

    product_ids = fields.Many2many('product.product',
        compute='_compute_available_products',
        string='Available Products')
    # Auto-computed from category and filters

    sequence = fields.Integer('Sequence', default=10)

    @api.depends('category_id', 'filter_domain')
    def _compute_available_products(self):
        for group in self:
            domain = [('categ_id', 'child_of', group.category_id.id)]
            if group.filter_domain:
                domain += safe_eval(group.filter_domain)
            group.product_ids = self.env['product.product'].search(domain)

Configuration Wizard Model

class FurnitureConfigurationWizard(models.TransientModel):
    _name = 'furniture.configuration.wizard'
    _description = 'Product Configuration Wizard'

    # Step 1: Base Product
    product_template_id = fields.Many2one('product.template',
        'Base Product', required=True,
        domain="[('is_furniture', '=', True)]")

    # Step 2: Dimensions
    furniture_height = fields.Float('Height (mm)', required=True)
    furniture_width = fields.Float('Width (mm)', required=True)
    furniture_depth = fields.Float('Depth (mm)', required=True)

    # Step 3: Material Selections (Dynamic based on BOM Groups)
    material_selection_ids = fields.One2many('furniture.material.selection',
        'wizard_id', 'Material Selections')

    # Step 4: Pricing
    unit_price = fields.Monetary('Unit Price', compute='_compute_price', currency_field='currency_id')
    total_price = fields.Monetary('Total Price', compute='_compute_price', currency_field='currency_id')
    quantity = fields.Float('Quantity', default=1.0)
    currency_id = fields.Many2one('res.currency', related='company_id.currency_id')

    # Validation
    constraint_errors = fields.Text('Constraint Errors', compute='_compute_constraints')
    is_valid = fields.Boolean('Valid Configuration', compute='_compute_constraints')

    def action_add_to_order(self):
        """Add configured product to current sales order"""
        self.ensure_one()
        if not self.is_valid:
            raise UserError(_("Configuration has validation errors"))

        # Create/update product variant with selected materials
        variant = self._create_product_variant()

        # Add to current order
        order = self.env.context.get('active_id')
        if order:
            self.env['sale.order.line'].create({
                'order_id': order,
                'product_id': variant.id,
                'product_uom_qty': self.quantity,
                'price_unit': self.unit_price,
            })

        return {'type': 'ir.actions.act_window_close'}

Material Selection Model (Dynamic Line Items)

class FurnitureMaterialSelection(models.TransientModel):
    _name = 'furniture.material.selection'
    _description = 'Material Selection for Configuration'

    wizard_id = fields.Many2one('furniture.configuration.wizard', 'Wizard')
    bom_group_id = fields.Many2one('furniture.bom.group', 'BOM Group', required=True)

    # Available options (computed from BOM Group)
    available_product_ids = fields.Many2many('product.product',
        compute='_compute_available_products',
        string='Available Materials')

    # User selection
    selected_product_id = fields.Many2one('product.product',
        'Selected Material',
        domain="[('id', 'in', available_product_ids)]")

    quantity = fields.Float('Quantity', default=1.0)
    uom_id = fields.Many2one('uom.uom', related='selected_product_id.uom_id')
    price = fields.Monetary('Price', compute='_compute_price', currency_field='currency_id')

    @api.depends('bom_group_id')
    def _compute_available_products(self):
        for line in self:
            line.available_product_ids = line.bom_group_id.product_ids

⚙️ Configuration

Setup Steps

  1. Create Product Categories:
    • Navigate to Inventory → Configuration → Product Categories
    • Create categories: "Veneers", "Edge Bands", "Hardware/Hinges", "Hardware/Handles", etc.
    • Add products to appropriate categories
  2. Define BOM Groups:
    • Navigate to Furniture → Configuration → BOM Groups
    • Create group "Veneer Materials" → Link to "Veneers" category
    • Create group "Edge Banding" → Link to "Edge Bands" category
    • Add filter domains if needed (e.g., [('is_veneer', '=', True)])
  3. Configure Base Products:
    • Navigate to Furniture → Products → Furniture Products
    • Create base products: "Door Veneer", "Cabinet", "Desk", etc.
    • Mark as is_furniture = True
    • Set default dimensions and constraints
  4. Set Pricing Rules:
    • Navigate to Furniture → Configuration → Pricing Rules
    • Define labor costs per product type
    • Set area/volume pricing formulas
    • Configure quantity discount thresholds
  5. Test Configuration:
    • Create test sales order
    • Click "Configure Furniture Product"
    • Complete wizard and verify pricing

Advanced Settings

  • Constraint Rules: Define technical constraints (min/max dimensions, material compatibility)
  • Multi-Currency: Configure rounding rules per currency
  • Workflow Automation: Auto-create MOs, auto-send quotations
  • User Permissions: Control who can configure products and approve custom pricing
