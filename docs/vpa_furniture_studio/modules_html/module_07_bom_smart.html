Module 7: vpa_furniture_bom_smart

Intelligent BOM Management with Material Substitution

Phase: Phase 2 Type: Manufacturing Status: Furniture-Specific Price: $5,000

Overview

vpa_furniture_bom_smart adds intelligence to Bill of Materials management with smart material substitution, alternative materials, BOM versioning, and automatic updates from the configurator. This module solves the common furniture manufacturing problem of running out of a specific veneer or material and needing to use alternatives without recreating entire BOMs.

Why This Matters: In furniture manufacturing, materials run out frequently (specific veneer colors, hardware models). Smart BOMs allow automatic substitution based on predefined rules, preventing production delays and manual BOM editing.
$5,000

Key Features

Material Substitution
Auto-substitute materials when primary is out of stock
Alternative Materials
Define backup options for each BOM component
BOM Versioning
Track BOM history and revert to previous versions
Auto-Update from Configurator
Sync configurator changes to existing BOMs
Cost-Based Selection
Choose alternatives based on cost optimization
Approval Workflows
Require approval for material substitutions

Technical Architecture

Smart BOM Model

class SmartBOM(models.Model): """Extends mrp.bom with smart substitution logic""" _inherit = 'mrp.bom' version = fields.Integer('Version', default=1) version_history_ids = fields.One2many( 'mrp.bom.version', 'bom_id', string='Version History' ) auto_substitute = fields.Boolean( 'Enable Auto Substitution', default=True, help="Automatically use alternatives when primary material unavailable" ) require_approval = fields.Boolean( 'Require Substitution Approval', default=False ) def _get_available_component(self, component_line): """ Intelligent component selection: 1. Check primary material stock 2. If unavailable, check alternatives 3. Select based on cost/availability """ primary = component_line.product_id # Check primary stock if primary.qty_available >= component_line.product_qty: return primary # Check alternatives for alt in component_line.alternative_ids.sorted('priority'): if alt.product_id.qty_available >= component_line.product_qty: if self.require_approval: self._request_substitution_approval(component_line, alt) return alt.product_id return False # Trigger procurement

Alternative Materials

class BomLineAlternative(models.Model): """Alternative materials for BOM components""" _name = 'mrp.bom.line.alternative' bom_line_id = fields.Many2one( 'mrp.bom.line', required=True, ondelete='cascade' ) product_id = fields.Many2one( 'product.product', string='Alternative Material', required=True ) priority = fields.Integer( 'Priority', default=10, help="Lower number = higher priority" ) cost_difference = fields.Monetary( string='Cost vs Primary', compute='_compute_cost_difference' ) notes = fields.Text('Substitution Notes') @api.depends('product_id', 'bom_line_id.product_id') def _compute_cost_difference(self): for alt in self: primary_cost = alt.bom_line_id.product_id.standard_price alt_cost = alt.product_id.standard_price alt.cost_difference = alt_cost - primary_cost # Example: Veneer alternatives BOM Line: Oak Veneer (primary) Alternative 1: Maple Veneer (priority: 1, cost: +$5) Alternative 2: Ash Veneer (priority: 2, cost: +$3) Alternative 3: Pine Veneer (priority: 3, cost: -$2)

BOM Versioning

class BOMVersion(models.Model): """Track BOM changes over time""" _name = 'mrp.bom.version' bom_id = fields.Many2one('mrp.bom', required=True) version = fields.Integer('Version Number') create_date = fields.Datetime('Created On') create_uid = fields.Many2one('res.users', 'Created By') bom_snapshot = fields.Text( 'BOM Snapshot (JSON)', help="Complete BOM structure at this version" ) change_notes = fields.Text('Change Summary') def action_revert_to_version(self): """Restore BOM to this version""" self.ensure_one() snapshot = json.loads(self.bom_snapshot) # Create new version before reverting self.bom_id._create_version_snapshot( change_notes=f"Reverted to v{self.version}" ) # Restore BOM lines self.bom_id._restore_from_snapshot(snapshot)

Use Cases & Examples

Example 1: Veneer Substitution

# BOM for "Arabica Door H2200×W900" Primary BOM: ├─ MDF Panel 2200×900×18mm (qty: 1) ├─ Walnut Veneer (qty: 2.5 m²) ← OUT OF STOCK │ └─ Alternatives: │ 1. Oak Veneer (cost: -$10, available: 150 m²) │ 2. Mahogany Veneer (cost: +$15, available: 80 m²) ├─ Edge Tape Walnut (qty: 6 m) └─ Door Hinges (qty: 3 pcs) System Action: ✓ Detects Walnut Veneer unavailable ✓ Auto-selects Oak Veneer (lowest cost alternative) ✓ Notifies production manager: "Substituted Walnut → Oak (-$10)" ✓ Updates manufacturing order ✓ Production continues without delay

Example 2: Hardware Substitution

# Cabinet with drawer slides shortage BOM Component: Premium Soft-Close Slides (OUT OF STOCK) Alternative 1: Standard Soft-Close Slides (cost: -$5, stock: 200) Alternative 2: Basic Ball-Bearing Slides (cost: -$12, stock: 500) Business Rules: - IF customer_type = 'premium' THEN use Alternative 1 - IF customer_type = 'standard' THEN use Alternative 2 - ALWAYS notify customer of substitution - ALWAYS update sales order line description

Example 3: BOM Version Rollback

# Version history for "Quadroto Desk W1600×D750" Version 4 (Current): Cost: $285 - Changed: Replaced MDF with plywood (+$15) - Date: 2025-11-15 - By: Victor Nyagaka Version 3: Cost: $270 - Changed: Added cable management tray (+$10) - Date: 2025-10-20 Version 2: Cost: $260 - Changed: Upgraded drawer slides (+$8) - Date: 2025-09-10 Version 1 (Original): Cost: $252 - Initial BOM from configurator - Date: 2025-08-01 Action: "Revert to Version 3" → System creates Version 5 = copy of Version 3 → Cost returns to $270 → Change logged: "Reverted to v3 - plywood too expensive"

Installation & Configuration

Prerequisites

  • Module 1: vpa_furniture_studio (BASE)
  • Module 6: vpa_furniture_manufacturing
  • Existing BOMs for furniture products

Setup Workflow

  1. Enable Smart BOMs: Navigate to Manufacturing → Configuration → Settings
  2. Configure Alternatives: For each BOM line, add 2-3 alternative materials
  3. Set Priorities: Define substitution order (1 = first choice)
  4. Enable Versioning: Activate BOM version tracking
  5. Test Substitution: Simulate out-of-stock scenario
Important: Always define alternatives for critical materials (veneers, hardware). Production will stop if no alternatives exist and primary is unavailable.
