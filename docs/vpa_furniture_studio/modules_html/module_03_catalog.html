📚 Module 3: vpa_furniture_catalog

Professional Digital Furniture Catalog Generator

📦 Phase: Phase 1 (Months 1-6) 🏷️ Type: Sales & Configuration ⚡ Priority: Medium $4,000

📋 Overview

The vpa_furniture_catalog module creates beautiful, professional digital catalogs from your furniture products automatically. Generate PDF catalogs, web-based e-catalogs, and price lists with a single click.

📄 PDF Catalogs

Print-ready professional catalogs with product photos and specifications

🌐 Web E-Catalogs

Interactive online catalogs with search and filtering

💰 Price Lists

Multi-currency price lists with customer-specific pricing

🎨 Template Designer

Drag-and-drop catalog layout designer

🎯 Key Features

1. Catalog Templates

  • Professional Layouts: Pre-designed templates (Modern, Classic, Minimalist)
  • Customizable Sections: Cover page, product pages, technical specs, index
  • Brand Identity: Company logo, colors, fonts, contact information
  • Multi-Language: Generate catalogs in multiple languages

2. Product Presentation

  • High-Quality Images: Multiple product photos (front, side, detail views)
  • Technical Specifications: Dimensions, materials, finishes, features
  • Variants Display: Show all dimension/color variants in grid format
  • Custom Fields: Add custom product attributes (sustainability rating, lead time)

3. Catalog Generation

# Generate Catalog Workflow
1. Select Products → Filter by category, series, price range
2. Choose Template → Modern/Classic/Minimalist layout
3. Configure Settings → Language, currency, pricing visibility
4. Generate → PDF (print) or HTML (web)
5. Publish → Download, email, or publish to website

4. Price List Management

Price List Type Features Use Case
Standard Retail Public prices, standard discounts General customers, walk-ins
Trade Partner Wholesale pricing, volume discounts Retailers, distributors
Project Quotation Custom pricing, negotiated rates Large projects, contractors
Material Cost Cost breakdown, no markup Internal costing, transparent pricing

5. Web E-Catalog Features

  • Interactive Navigation: Category sidebar, search bar, filters
  • Product Zoom: Click to enlarge images, 360° views
  • Quick Actions: Add to inquiry, download spec sheet, request quote
  • Responsive Design: Works on desktop, tablet, mobile
  • Share Links: Generate shareable links to specific products
✅ Integration: Web catalogs integrate with vpa_furniture_portal for customer login and personalized pricing.

🔧 Technical Architecture

Database Models

Catalog Template Model

class FurnitureCatalogTemplate(models.Model):
    _name = 'furniture.catalog.template'
    _description = 'Catalog Template'

    name = fields.Char('Template Name', required=True)
    layout_style = fields.Selection([
        ('modern', 'Modern'),
        ('classic', 'Classic'),
        ('minimalist', 'Minimalist'),
        ('custom', 'Custom')
    ], default='modern')

    # Brand Identity
    company_id = fields.Many2one('res.company', 'Company')
    logo = fields.Binary('Company Logo')
    primary_color = fields.Char('Primary Color', default='#2c3e50')
    secondary_color = fields.Char('Secondary Color', default='#27ae60')
    font_family = fields.Selection([
        ('arial', 'Arial'),
        ('helvetica', 'Helvetica'),
        ('times', 'Times New Roman'),
        ('georgia', 'Georgia')
    ])

    # Layout Settings
    page_size = fields.Selection([('A4', 'A4'), ('Letter', 'Letter')], default='A4')
    products_per_page = fields.Integer('Products Per Page', default=4)
    show_prices = fields.Boolean('Show Prices', default=True)
    show_dimensions = fields.Boolean('Show Dimensions', default=True)
    show_materials = fields.Boolean('Show Materials', default=True)

Catalog Generation Model

class FurnitureCatalog(models.Model):
    _name = 'furniture.catalog'
    _description = 'Furniture Catalog'

    name = fields.Char('Catalog Name', required=True)
    template_id = fields.Many2one('furniture.catalog.template', 'Template')

    # Product Selection
    product_ids = fields.Many2many('product.template', 'Product Selection')
    category_ids = fields.Many2many('product.category', 'Categories Filter')

    # Settings
    language = fields.Selection([
        ('en_US', 'English'),
        ('fr_FR', 'French'),
        ('es_ES', 'Spanish')
    ], default='en_US')
    currency_id = fields.Many2one('res.currency', 'Currency')
    pricelist_id = fields.Many2one('product.pricelist', 'Price List')

    # Generation
    catalog_type = fields.Selection([
        ('pdf', 'PDF Catalog'),
        ('html', 'Web E-Catalog')
    ], required=True)
    pdf_file = fields.Binary('PDF File', readonly=True)
    html_content = fields.Html('HTML Content', readonly=True)

    state = fields.Selection([
        ('draft', 'Draft'),
        ('generated', 'Generated'),
        ('published', 'Published')
    ], default='draft')

    def action_generate_catalog(self):
        """Generate catalog based on settings"""
        self.ensure_one()
        if self.catalog_type == 'pdf':
            self._generate_pdf_catalog()
        else:
            self._generate_html_catalog()
        self.state = 'generated'
