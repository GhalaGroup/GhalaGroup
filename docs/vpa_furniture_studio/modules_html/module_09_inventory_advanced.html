Module 9: vpa_inventory_advanced

Multi-Box Tracking & Partial Shipment Prevention

Phase: Phase 1 Type: Inventory & Warehouse Status: Furniture-Specific Price: $5,000

Overview

vpa_inventory_advanced solves the unique challenge of furniture products that ship in multiple boxes. The module tracks "Box 1 of 3", "Box 2 of 3", prevents partial shipments, and ensures complete orders before delivery. Advanced UOM handling supports furniture-specific measurements (m², m³, linear meter).

Why This Matters: Furniture often ships disassembled in multiple packages. Sending incomplete sets (2 of 3 boxes) creates customer complaints, returns, and costly re-shipments. This module prevents partial deliveries and tracks multi-box integrity.
$5,000

Key Features

Multi-Box Tracking
Track "Box 1 of 3", "Box 2 of 3" relationships
Partial Shipment Prevention
Block delivery if all boxes not ready

Support m², m³, linear meters, piece

Technical Architecture

Multi-Box Product Model

class MultiBoxProduct(models.Model): """Products that ship in multiple boxes""" _inherit = 'product.template' is_multi_box = fields.Boolean('Ships in Multiple Boxes') box_count = fields.Integer('Number of Boxes', default=1) box_ids = fields.One2many( 'product.box', 'product_tmpl_id', string='Box Details' ) allow_partial_shipment = fields.Boolean( 'Allow Partial Shipment', default=False, help="If False, all boxes must be ready before shipping" ) class ProductBox(models.Model): """Individual box information""" _name = 'product.box' product_tmpl_id = fields.Many2one('product.template') sequence = fields.Integer('Box Number') name = fields.Char(compute='_compute_name', string='Box Label') # Box dimensions box_width = fields.Float('Width (mm)') box_height = fields.Float('Height (mm)') box_depth = fields.Float('Depth (mm)') box_weight = fields.Float('Weight (kg)') # Contents contents = fields.Text('Box Contents') barcode = fields.Char('Box Barcode') @api.depends('sequence', 'product_tmpl_id.box_count') def _compute_name(self): for box in self: total = box.product_tmpl_id.box_count box.name = f"Box {box.sequence} of {total}"

Delivery Validation

class StockPicking(models.Model): """Extended delivery order with box validation""" _inherit = 'stock.picking' has_multi_box_products = fields.Boolean( compute='_compute_multi_box' ) missing_boxes = fields.Text( compute='_compute_missing_boxes', string='Incomplete Products' ) def button_validate(self): """Override validation to check box completeness""" self.ensure_one() # Check for incomplete multi-box products for move in self.move_lines: product = move.product_id.product_tmpl_id if product.is_multi_box and not product.allow_partial_shipment: if not self._validate_all_boxes_ready(move): raise UserError( f"Cannot ship {product.name} - " f"Not all boxes are ready. " f"Missing: {self._get_missing_boxes(move)}" ) return super().button_validate() def _validate_all_boxes_ready(self, move): """Check if all boxes for product are in picking""" product = move.product_id.product_tmpl_id expected_boxes = product.box_count # Count boxes in this picking boxes_in_picking = self.env['stock.move.line'].search_count([ ('picking_id', '=', self.id), ('product_id', '=', move.product_id.id), ]) return boxes_in_picking == expected_boxes

Installation & Configuration

Setup Steps

  1. Install module from Apps
  2. Navigate to Products → Select furniture product
  3. Enable "Ships in Multiple Boxes"
  4. Define box count and details
  5. Configure box dimensions & weights
  6. Set partial shipment policy
  7. Generate box barcodes
  8. Test delivery validation
Important: Always set "Allow Partial Shipment" to FALSE for products where incomplete delivery is unacceptable. Enable only for products where partial delivery is acceptable (e.g., modular systems).
