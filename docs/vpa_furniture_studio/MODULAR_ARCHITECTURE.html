1. System Overview

VPA Furniture Studio is a comprehensive, modular ERP ecosystem specifically designed for custom furniture manufacturing. Built on Odoo 19 Enterprise, it provides end-to-end solutions from sales configuration to delivery.

Key Business Problems Solved

  • Complex Product Configuration: Customers can configure custom furniture with dimensions, materials, and options in real-time
  • Accurate Cost Tracking: Historical production costs replace fixed estimates, improving profitability
  • Material Waste Reduction: CNC nesting optimization reduces material waste by 5-15%
  • Production Visibility: Real-time shop floor tracking from mobile devices
  • Quality Assurance: Mobile inspections with photo documentation
  • Customer Service: Self-service portal with order tracking and 3D visualization

Target Market

Business Size Annual Revenue Employees Monthly Production Recommended Package
Small < $500k 1-10 < 50 units Starter
Medium $500k - $2M 10-50 50-200 units Professional
Large $2M - $10M 50-200 200-1,000 units Advanced/Enterprise
Enterprise $10M+ 200+ 1,000+ units Ultimate

Technology Stack

  • Platform: Odoo 19 Enterprise
  • Backend: Python 3.10+
  • Database: PostgreSQL 12+
  • Frontend: JavaScript (OWL Framework), QWeb, Bootstrap
  • Mobile: Native Android (Java/Kotlin)
  • Reporting: QWeb Reports, PDF Generation
  • Integration: REST API, XML-RPC

2. Modular Architecture

Modular Design Philosophy: VPA Furniture Studio is designed as 17 independent but interconnected modules. Customers can start with essential modules and add features as they grow, paying only for what they need.

Module Categories

Category Modules Purpose
Core Foundation 1 module Base functionality required by all modules
Sales & Configuration 3 modules Product configuration, catalog management, customer showcase
Pricing & Finance 2 modules Cost tracking, profitability, quotations
Manufacturing 3 modules Production orders, smart BOMs, CNC optimization
Warehouse & Logistics 3 modules Inventory management, barcode scanning, label printing
Production Floor 2 modules Shop floor control, quality inspections
Analytics 1 module Business intelligence, reporting
Customer-Facing 2 modules Customer portal, delivery scheduling

Universal vs Furniture-Specific Modules

5 Universal Modules can be sold to ANY business (not just furniture):

  • ✅ Label Designer - Retail, warehouses, manufacturing
  • ✅ Barcode/RFID - Any business with inventory
  • ✅ Quality Control - Manufacturing, food, pharma
  • ✅ Delivery Scheduling - Appliances, HVAC, furniture
  • ✅ Product Catalogue - Any business with product showcase

12 Furniture-Specific Modules solve industry problems:

  • Dimension-based configuration (H×W×D)
  • Material selection from inventory categories
  • Historical furniture production costing
  • CNC nesting for wood/veneer sheets
  • Series/collection management

3. All 17 Modules - Detailed Specifications

Module 1: vpa_furniture_studio (BASE)

$2,000

Phase: Phase 1 | Type: Core Foundation | Status: Required by ALL

Purpose

Foundation module that provides basic furniture product types, dimension management, and furniture-specific UOM handling. Required by all other modules.

Key Features

  • Custom furniture product types
  • Dimension fields (Height × Width × Depth)
  • Furniture categories (Door, Cabinet, Panel, Shelf, etc.)
  • UOM handling (piece, m², m³, linear meter)
  • Product template extensions
  • Basic configuration interface

Database Models

class FurnitureProduct(models.Model): _inherit = 'product.template' is_furniture = fields.Boolean('Is Furniture Product') furniture_type = fields.Selection([ ('door', 'Door'), ('cabinet', 'Cabinet'), ('desk', 'Desk'), ('table', 'Table'), ('chair', 'Chair'), ('shelf', 'Shelf'), ('panel', 'Panel'), ]) # Dimensions furniture_height = fields.Float('Height (mm)') furniture_width = fields.Float('Width (mm)') furniture_depth = fields.Float('Depth (mm)') # Computed areas/volumes area_m2 = fields.Float('Area (m²)', compute='_compute_area') volume_m3 = fields.Float('Volume (m³)', compute='_compute_volume')

Dependencies

  • Odoo Core: product, stock, uom

Use Cases

  • Create furniture products with dimensions
  • Calculate areas and volumes automatically
  • Organize products by furniture type
  • Foundation for all furniture-specific features

Module 2: vpa_furniture_configurator

$6,000

Phase: Phase 1 | Type: Sales & Configuration | Requires: BASE

Purpose

Interactive product configurator with BOM groups allowing material selection from inventory categories. Real-time pricing calculation based on customer selections.

Key Features

  • BOM Groups linked to product categories
  • Dynamic material selection (veneer, wood, hardware)
  • Real-time price calculation
  • Assembly options (frame, installation)
  • Parent-child line structure in sales orders
  • Material premium pricing
  • Configuration wizard interface

Example Configuration Flow

1. Customer selects: "Door Veneer H2200×W900" 2. System asks: "Which veneer?" (from inventory category "Veneer") - Oak Veneer (+$0) - Walnut Veneer (+$50) - Mahogany Veneer (+$45) - Teak Veneer (+$70) 3. System asks: "Frame?" (from inventory category "Frames") - No Frame - MDF Frame T120mm (+$155) - Wood Frame T150mm (+$180) 4. System asks: "Installation?" - No (+$0) - Professional Installation (+$50) 5. System generates: - Door Assembly (parent line) → Total: $485 ├─ Veneer Door H2200×W900 - Walnut ├─ MDF Frame T120mm └─ Professional Installation

BOM Groups Architecture

class BomGroup(models.Model): _name = 'furniture.bom.group' name = fields.Char('Group Name') # "Veneer Selection" product_category_id = fields.Many2one('product.category') sequence = fields.Integer() # Price adjustments price_adjustment_ids = fields.One2many( 'furniture.bom.group.adjustment', 'group_id' ) @api.depends('product_category_id') def _compute_available_products(self): """Get all products from selected category""" for group in self: products = self.env['product.product'].search([ ('categ_id', '=', group.product_category_id.id), ('active', '=', True), ]) group.available_product_ids = products

Module 17: vpa_product_catalogue ⭐ NEW

$6,000

Phase: Phase 1 | Type: Universal (Sales) | Requires: BASE

Purpose

Customer-facing product catalog system with series/collection management (Quadroto, Arabica, ModernCraft, etc.). Links catalog items to Odoo inventory with multi-image gallery and technical file tracking.

Based on Your Real Data: This module is designed specifically around your Product Catalogue.csv structure with 8 series, 235+ products, and dimension variants.

Key Features

  • Series/Collection Management (Quadroto, Arabica, ModernCraft, Ottomania, Doppio, W-Series, SW-Series)
  • Product Family grouping (dimension variants)
  • Multi-image galleries per product
  • Technical file tracking (SolidWorks, Sketchup, 3D Renders, eDrawing, DXF)
  • Bidirectional link to inventory (Catalog ↔ Product)
  • Customer-facing showcase interface
  • Sub-category organization (Executive Desk, Workstation, Meeting Table, etc.)
  • Variant dimension selector (select W×D combinations)

Database Schema

class ProductCatalogueSeries(models.Model): """Series like Quadroto, Arabica, etc.""" _name = 'product.catalogue.series' name = fields.Char('Series Name') # "Quadroto" description = fields.Html('Description') logo = fields.Binary('Series Logo') color_scheme = fields.Char('Brand Color') class ProductCatalogueItem(models.Model): """Individual catalog entry""" _name = 'product.catalogue.item' name = fields.Char('Product Name') item_code = fields.Char('Item Code') # "C1M/OFC0401" series_id = fields.Many2one('product.catalogue.series') sub_category_id = fields.Many2one('product.catalogue.subcategory') # Link to inventory product_tmpl_id = fields.Many2one('product.template') # Dimensions width = fields.Float('Width (mm)') depth = fields.Float('Depth (mm)') height = fields.Float('Height (mm)') # Technical files has_solidworks = fields.Boolean() has_sketchup = fields.Boolean() has_3d_renders = fields.Boolean() has_edrawing = fields.Boolean() has_dxf = fields.Boolean() # Images image_ids = fields.One2many('product.catalogue.image', 'catalogue_item_id') class ProductCatalogueFamily(models.Model): """Groups dimension variants together""" _name = 'product.catalogue.family' name = fields.Char('Family Name') # "Quadroto Office Desk 2 Side Legs" variant_ids = fields.One2many('product.catalogue.item', 'family_id')
