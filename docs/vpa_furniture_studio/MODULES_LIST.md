## 🎨 Icon Design Requirements

### General Guidelines

**Size:** 128×128 pixels (Odoo standard)
**Format:** PNG with transparency
**Style:** Flat design, modern, professional
**Color:** Each module has primary + accent colors
**Consistency:** All icons should feel like part of the same family

## 📏 Technical Specifications

### Image Requirements

- **Format:** PNG with transparency
- **Size:** 128×128 pixels (Odoo standard)
- **Resolution:** 72 DPI minimum
- **Color Mode:** RGB
- **Background:** Transparent
- **File Naming:** `module_name_icon_128.png`

### Design Standards

**Do's:**
✅ Use flat design principles
✅ Keep designs simple and recognizable
✅ Maintain consistent style across all icons
✅ Use the specified color schemes
✅ Ensure icons are legible at small sizes
✅ Test on light and dark backgrounds

**Don'ts:**
❌ Don't use gradients (flat design only)
❌ Don't add drop shadows or 3D effects
❌ Don't use more than 2 colors per icon
❌ Don't use small details that won't scale
❌ Don't use photographs or realistic imagery
❌ Don't deviate from the color palette
