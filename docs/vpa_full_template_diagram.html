8. Critical Technical Notes

⚠️ Important Implementation Details

  • Zero Margins: All page margins are 0 except bottom (50mm for footer)
  • Footer Separation: Footer is NOT in main template - rendered separately via --footer-html
  • Footer Parameter Conflict: Must clear Odoo's default footer parameter to prevent override
  • DOCTYPE Required: Footer HTML must start with <!DOCTYPE html> (added in controller, not XML)
  • Authentication: Footer route uses auth='public' with .sudo() for wkhtmltopdf access
  • Z-Index Layering: Circle (-1), Content (1-2), Wave (0), Footer Content (101)
  • Multi-Page: Footer automatically appears on ALL pages (wkhtmltopdf handles this)
  • Context Flag: vpa_force_zero_margins and vpa_template_id control PDF generation

💡 Customization Tips

  • Adjust --margin-bottom if footer height changes (current: 50mm for 55mm footer)
  • Footer padding creates breathing room: 15px top, 20px sides, 20px bottom
  • Wave opacity at 0.1 provides subtle background without overwhelming content
  • Font hierarchy: 28pt (title) → 11pt (total) → 10pt (table) → 9pt (info) → 8pt (footer title) → 7.5pt (footer content)
  • Use header_circle_size to adjust decorative circle (550px = subtle, 800px = bold)
