6. Important Technical Notes

  • Footer Height vs Margin: Footer is 55mm tall, but margin is 50mm. This 5mm overlap allows the wave shape to extend to the page edge for a seamless look.
  • Z-Index Layering: Wave (z-index: 0) sits behind content (z-index: 101), creating depth.
  • Font Sizes: Titles use 8pt, content uses 7.5pt for hierarchy.
  • Responsive Padding: 15px top, 20px sides, 20px bottom provides breathing room.
  • DOCTYPE Required: Footer HTML must start with <!DOCTYPE html> (added in controller).
  • Authentication: Footer route uses auth='public' with .sudo() so wkhtmltopdf can fetch it.
